# Estudo em Dia

Organizador de tarefas e prazos de estudo. Projeto pessoal de portfólio de **Rayane Araújo Teles**, iniciado em 25/10/2026.

**Estado atual: planejamento.** Este repositório contém o escopo inicial; a aplicação ainda não foi implementada ou publicada.

## Problema

Reunir atividades de diferentes disciplinas em um lugar, acompanhar o que está pendente e visualizar os próximos prazos.

## Primeira versão proposta

- Cadastrar tarefa com título, disciplina e prazo opcional.
- Listar, editar, concluir e excluir tarefas com confirmação.
- Filtrar por disciplina e estado: pendente ou concluída.
- Mostrar totais e próximos prazos sem usar somente cor para comunicar estados.
- Manter os dados ao recarregar a página, inicialmente no próprio navegador.
- Funcionar em celular e computador, com navegação por teclado e mensagens de erro claras.

## Etapas de construção

| Etapa | Entrega | Critério para avançar |
| --- | --- | --- |
| 1 — Interface | Layout responsivo e fluxo de criação/listagem | Cadastrar e consultar tarefas em tela pequena e grande |
| 2 — Funcionalidades | Edição, conclusão, exclusão, filtros e armazenamento local | Fluxos funcionando, inclusive dados vazios ou inválidos |
| 3 — Qualidade | Testes dos comportamentos, acessibilidade e documentação | Evidências de teste e instruções reproduzíveis |
| 4 — Evolução full stack | API, banco de dados e separação dos dados por usuário | Contratos e autenticação definidos antes de implementar |
| 5 — Publicação | Demonstração e documentação do ambiente | Versão testada, sem segredos no repositório |

## Decisões em aberto

A escolha de framework e hospedagem será registrada ao iniciar a implementação. A versão inicial pode explorar HTML, CSS e JavaScript; API e banco entram em uma etapa posterior. Nenhum serviço pago foi escolhido.
